# 2026-11-05

## sqless 5.0.1 发布：修 Metadata-Version 2.5 上传失败
- 现象：`twine upload dist/*` 报 `InvalidDistribution: Invalid distribution metadata: '2.5' is not a valid metadata version`。
- 根因：hatchling >= 1.30 的 `DEFAULT_METADATA_VERSION` 改为 `"2.5"`（`hatchling/metadata/spec.py:12`），而 twine 6.2 + packaging 25.0 只认到 2.4，PyPI 侧同样未接受 2.5。
- 修法：`pyproject.toml` 给 wheel / sdist 两个 target 显式设置 `core-metadata-version = "2.4"`（比钉 hatchling 版本更精准；hatchling 各 target 读 `self.target_config.get("core-metadata-version", DEFAULT_METADATA_VERSION)`）。
- 构建用 `uv build`（本机 python 无 hatchling，走隔离构建拉最新 hatchling）。校验：wheel/sdist 的 METADATA/PKG-INFO 首行均为 `Metadata-Version: 2.4`，`twine check` PASSED，上传成功 → https://pypi.org/project/sqless/5.0.1/
- 待办：`pyproject.toml` 的该改动尚未提交。
